> Claude Code에 그대로 전달할 것. 이 문서는 시각 디자인과 레이아웃만 다룬다.

---

## 0. 건드리지 않을 것

- 비즈니스 로직, 만세력 계산, 라우팅, API, 데이터 스키마 — 수정 금지.
- 모든 텍스트·라벨·용어·한자 표기 — 수정 금지. 기존 코드에 적용된 표기 규칙(한글 병기 등)을 **그대로 유지**한다. 이 문서는 어떤 문구도 새로 정하지 않으며, 화면 예시에 나오는 글자는 자리 표시일 뿐이다. 리디자인 과정에서 기존 라벨을 줄이거나 바꾸지 않는다.
- 없는 수치·항목을 만들지 않는다. 데이터가 없으면 섹션을 만들지 말고 빈 상태로 둔다.
- 제목만 있고 내용이 빈 영역을 남기지 않는다.

작업 전 현재 코드베이스(프레임워크, 스타일링 방식, 컴포넌트 구조)를 먼저 파악하고 그 관례를 따른다. 새 스타일링 라이브러리를 임의로 추가하지 않는다.

## 1. 디자인 방향

한 줄 정의: 어두운 판 위에 결과를 또렷하게 세운다. 장식보다 판독성이 먼저다.

명리 특유의 분위기는 **색·서체·얇은 선·각진 프레임**으로 만든다. 복잡한 문양이나 밀도 높은 그래픽으로 만들지 않는다.

### 1-1. 이원 서피스

브리프의 `#F0F2F8`(라이트)와 `다크 기조`를 충돌로 두지 않고 역할로 나눈다.

| 서피스 | 적용 | 배경 |
|---|---|---|
| 입력·요약 (다크) | 히어로, 네 기둥 판, 궁합 입력, 결과 상단 | #0C1020 |
| 읽기 (라이트) | 결과 본문, 풀이, FAQ, 정책 | #F0F2F8 |

전환은 하드 컷 + hairline 1개. 그라데이션 페이드 금지.

## 2. 디자인 토큰

`src/styles/tokens.css`에 정의하고, 이후 컴포넌트는 raw hex 없이 변수만 참조한다.


:root {
  /* 다크 서피스 */
  --ink-900:#0C1020; --ink-800:#131A2E; --ink-700:#1B2340;
  --line-dark:#222B4A; --line-dark-strong:#2A3454;

  /* 라이트 서피스 */
  --paper:#F0F2F8; --paper-raised:#FFFFFF; --line-light:#D3D8E8;

  /* 텍스트 */
  --on-dark:#E7EAF6; --on-dark-2:#9AA3C4; --on-dark-3:#6F7AA0;
  --on-light:#10141F; --on-light-2:#3A4160; --on-light-3:#5C6483;

  /* 강조 — 선·포인트 전용 */
  --flux-cyan:#57D8E8; --flux-violet:#9B7BF0;
  --flux-grad:linear-gradient(90deg,#57D8E8,#9B7BF0);
  --cinnabar:#C4452F;  /* 화면당 1회 */
  --gilt:#C9A227;

  /* 다섯 기운 색 — 해당 시각화 안에서만 */
  --wx-1:#3E8E7E; --wx-2:#C4452F; --wx-3:#C9A227;
  --wx-4:#A8AFC4; --wx-5:#3B5BA5;
  --wx-3-text:#8A6B12; --wx-4-text:#6B7288; /* 라이트 배경 텍스트용 */

  /* 반경 */
  --r-sm:6px; --r-md:10px; --r-frame:4px;
}


색 사용 규칙
1. `--flux-grad`는 1px 선·아이콘 스트로크에만. 버튼 배경·카드 배경·텍스트에 금지.
2. `--cinnabar`는 화면당 최대 1회. 단일 포인트(선택 상태 표시, 주의 배지).
3. 다섯 기운 색은 해당 차트·배지 안에서만. 일반 UI(버튼·링크·상태)에 쓰면 색 언어가 무너진다.
4. 라이트 배경에서 텍스트로 쓸 때는 --wx-3-text, --wx-4-text 변형을 쓴다. 대비 4.5:1 미달 색은 텍스트 금지.

## 3. 타이포그래피


제목:        Noto Serif KR 500/600  (+ 라틴 Lora 500/600)
본문:        Pretendard Variable 400/500/600
수치·라벨:   IBM Plex Mono 400/500


- 서브셋 필수. Noto Serif KR 전체 로딩은 수 MB. unicode-range 서브셋 + font-display:swap, 폴백 메트릭(`size-adjust`)을 맞춰 CLS를 0으로 만든다.
- 모든 수치에 font-variant-numeric:tabular-nums 강제.

| 역할 | 폰트 | 모바일 | 데스크톱 |
|---|---|---|---|
| H1 | Serif 600 | 26px / 1.35 | 38px / 1.32 |
| H2 | Serif 600 | 19px / 1.4 | 24px / 1.4 |
| 카드 제목 | Serif 500 | 16px | 17px |
| 본문 | Pretendard 400 | 15px / 1.7 | 15px / 1.7 |
| 보조 | Pretendard 400 | 13px / 1.6 | 13px / 1.6 |
| 라벨 | Mono 400 | 12px | 11px |
| 대형 수치 | Mono 500 | 40px | 48px |

하한선: 모바일에서 12px 미만 텍스트를 쓰지 않는다. 데스크톱 11px 라벨은 모바일에서 12px로 올린다.

## 4. 모바일 우선 레이아웃

375px에서 먼저 설계하고 넓은 화면으로 확장한다. 데스크톱을 축소하지 않는다.

### 4-1. 기본 규칙
- 좌우 패딩 20px 고정. 섹션 상하 여백 모바일 48px / 데스크톱 96px.
- 컨테이너 max-width 1120px, 읽기 컬럼 680px.
- 터치 타겟 최소 44×44px. 인접 타겟 사이 간격 최소 8px.
- env(safe-area-inset-*) 적용 — 하단 고정 요소·풋터에 필수.
- 8pt 스페이싱 기준.

### 4-2. 반응 규칙
| 요소 | 모바일 (~640px) | 데스크톱 |
|---|---|---|
| 진입 카드 3개 | 1열 세로 스택, 카드 높이 축소 | 3열 |
| 네 기둥 판 | 4열 유지, 글자만 축소 | 4열 |
| 다섯 기운 막대 | 5열 유지, 막대 폭 축소 | 5열 |
| 결과 점수 + 설명 | 세로 스택 (점수 위, 설명 아래) | 좌우 2열 |
| 보조 카드 2개 | 1열 스택 | 2열 |
| 표 | 카드형 리스트로 변환 | 표 유지 |

- 가로 스크롤 금지. 표를 가로로 밀게 만들지 말고 라벨 / 값 스택 카드로 재구성한다.
- 4열·5열 그리드는 모바일에서도 유지한다 — 세로로 풀면 "네 기둥"·"다섯 기운"이라는 구조 자체가 사라진다. 대신 글자·막대만 줄인다.

### 4-3. 주요 동작의 도달성
- 주 CTA는 **하단 sticky bar**(높이 56px + safe-area)로 고정. 스크롤 중 항상 손가락 닿는 위치에 둔다.
- 상단 헤더는 로고 + 햄버거만. 모바일에서 내비 3개를 가로로 늘어놓지 않는다.
- 관계 선택(가족·친구·연인·동료)은 2×2 그리드, 각 셀 최소 높이 64px.
