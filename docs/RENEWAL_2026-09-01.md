## 1단계 — 토큰

이 앱은 색·모서리·그림자가 `:root` 한 곳에 모여 있어서, 값만 갈아 끼우면 전체가 함께 넘어갑니다.
**이름은 그대로 두고 값만 바꿨습니다.** (`--ink-900`, `--gold` 같은 이름이 수백 곳에서 쓰이고 있어
이름을 바꾸면 그 전부를 함께 고쳐야 합니다.)

| 자리 | 예전 | 지금 |
|---|---|---|
| 지면 | `#0C1020` 어두운 남색 | `#efe9dd` 종이색 |
| 카드 | `#131A2E` | 지면과 같은 색 + 괘선 (`#d8d0c0`) |
| 글자 | `#E7EAF6` | 먹 `#1f1c17` / 보조 `#5d574c` |
| 강조(`--gold`) | `#DD8A78` | 낙관 `#AF2B25` |
| 채운 버튼(`--gold-fill`) | `#B93E2A` | 먹 `#1f1c17` + 종이색 글자 |
| 모서리 | 4px | 0 (원형은 배지·아바타에만) |
| 그림자 | 있음 | 없음 (모달만 아주 옅게) |

- 어두운 판을 전제로 박아 둔 반투명 흰색 66곳을 먹으로 뒤집었습니다(알파는 0.6배로 낮춤).
- 공유 카드(캔버스)도 같은 팔레트로 옮겼습니다 — 카드만 어두우면 눌러 들어온 화면과 다른 서비스로 보입니다.

### 시안에서 일부러 벗어난 두 곳 (근거 있음)

1. **`--ink-faint`** — 시안의 '라벨/캡션' `#8a8272`는 종이 위 3.15:1입니다. 이 앱에서 이 토큰은
   결제·보안 고지문에도 쓰여서 그 값을 그대로 쓸 수 없습니다. `#736c5f`(4.62:1)로 한 단 내렸습니다.
   순수 장식 라벨 자리에는 시안 값을 그 자리에서 직접 쓰면 됩니다.
2. **`--field-line`** — 시안의 '선(진함)' `#c9c0ae`는 1.49:1이라 "여기가 입력칸이다"를 못 알립니다.
   폼 컨트롤 경계 기준(3:1)에 맞춰 `#8a8272`(3.15:1)로 올렸습니다.

## 2단계 — 서체 · 캐릭터 · 화면

### 서체
- 제목·숫자·한자를 **Gowun Batang 400·700**으로 바꿨습니다(시안 지정).
- **구글에서 부르지 않습니다.** 조각 190개를 받아 `fonts/gowun-batang/` 에 두고 우리 서버에서 내려줍니다.
  처리방침 제5조("외부에서 불러오는 이미지·글꼴·스크립트가 없습니다")를 지키기 위해서입니다.
  실측: 첫 화면에서 27조각을 받고, 외부 요청은 0건입니다.
- 못 받으면 Noto Serif KR → 기기 명조 순으로 내려갑니다.

### 캐릭터
- 시안의 그림 37컷으로 교체했습니다. 성격유형 16종 × 남·여 32컷 + 오행 5컷.
- **키(`mENFP`·`e0`)는 바꾸지 않았습니다.** 파일 이름에만 성별을 붙입니다 —
  `mENFP-f.webp` / `mENFP-m.webp`, 성별을 모를 때 쓰는 `mENFP.webp`.
- 성별은 **사주 계산에 이미 받고 있는 값**(`profile.gender`)을 씁니다. 질문을 새로 만들지 않았습니다.
- 캐시 열쇠를 키가 아니라 그림 이름으로 바꿨습니다 — 키로 잡으면 남녀 그림이 서로 덮어씁니다.
- 원본 8컷의 아래쪽에 원본 시트의 유형 이름 조각이 남아 있어 잘라냈습니다.

### 화면
- **홈** — 성격유형 캐릭터 + 오른쪽 아래 오행 배지, 점수는 명조 700, 기능 줄에 한자 번호(一二).
- **첫 화면** — 밝은 종이 띠 위에 캐릭터 넷을 겹쳐 세우고 "내 캐릭터가 어떻게 정해지는지" 한 줄.
- **인연 등급** — 시안의 5등급 색·선 굵기·점선(상극)을 그대로. 선에 쓰는 색과 글자에 쓰는 색을
  따로 둡니다(선은 그림 3:1, 글자는 본문 4.5:1로 기준이 다릅니다).
- **궁합** — 두 캐릭터 사이에 등급 색 연결선. 등급 배지는 각진 상자 + 등급색 테두리.
- **여덟 글자 표** — 오행 타일 색을 시안 값으로. 칸 이름은 넷이 **같은 자리에서 접히게** 묶었습니다
  (예전에는 '태어난 시각'만 두 줄이라 글자 칸의 윗변이 들쭉날쭉했습니다 — 대표님 지적).

## 3단계 — 넓은 화면과 프로필 만들기 (2026-09-02)

### 넓은 화면 (1080px 이상)
- `#app`을 1312px까지 열고, 화면 안 카드를 **두 단**으로 폅니다.
- CSS `grid`가 아니라 `columns:2` + `column-span`을 씁니다. grid로 하면 짧은 카드 아래에
  큰 구멍이 남습니다(실제로 그렇게 나와서 바꿨습니다).
- 카드가 아닌 것(제목·버튼·안내문)은 `column-span:all`로 두 단을 가로지릅니다.
- 실측 1440px: view 1184px · 홈 2장 / 오늘 8장 / 내 사주 6장 · 가로 넘침 없음 · 콘솔 오류 0.

### 프로필 만들기 3단계 — 화면만 시안으로 (입력 흐름은 그대로)
**넣는 순서·묻는 값·검사 규칙은 하나도 안 바꿨습니다.** 보이는 것만 바꿨습니다.

| 자리 | 예전 | 지금 |
|---|---|---|
| 진행 표시 | 6px 알약 막대(33/66/100%) | 칸마다 괘선을 그은 세 칸 — `一 사주 정보 · 二 성격유형 · 三 확인` |
| 큰 제목 위 작은 글씨 | "프로필 만들기 · 1/3" | "프로필 만들기" (단계 수는 위 표시가 알려줌) |
| 고른 단추(양력/음력·성별) | 옅은 붉은 바탕 + 붉은 글자 | 먹 바탕 + 종이색 글자, 칸 사이 괘선 |
| 성격유형 16칸 | 반투명 테두리 | 괘선 테두리, 고른 칸은 먹 바탕 |
| 넓은 화면 | 입력줄이 1,650px까지 늘어남 | 680px로 묶어 가운데 정렬 (`.setup-view`) |

지금 칸은 먹, 지나온 칸은 회색, 아직 안 온 칸은 옅은 선 — 세 상태를 색으로 구분합니다.

### 정의가 없던 `--line` 을 복구했습니다 (같이 발견)
`var(--line)`을 쓰는 자리가 **열 곳**인데 그 토큰이 어디에도 정의돼 있지 않았습니다.
CSS에서 정의 없는 변수를 쓰면 그 선언 전체가 무효가 되므로, **그 열 곳의 괘선이 아예 안 그려지고
있었습니다.** `#d8d0c0`(시안의 기본 선)으로 정의했고, 실제로 그려지는 것을 브라우저에서
확인했습니다: 입력 줄 구분선 · 성격유형 네 축의 '같음/갈림' 배지 테두리 · 축 설명 위 구분선 ·
모임 궁합에서 쌍끼리 나누는 선.
