# 빠른 층 검사 폴더

여기에 `.cjs` 파일을 넣으면 `bash verify.sh`(빠른 층)가 자동으로 돌립니다.
`verify.sh`를 고칠 필요가 없습니다 — 그래야 검사가 실제로 쌓입니다.

- 통과 = 종료코드 0, 실패 = 0이 아닌 값
- 첫 인자로 로컬 서버 주소가 들어옵니다 (`process.argv[2]`)
- 공용 부품은 `../_lib.cjs`

## 여기에 넣어도 되는 것

**몇 초 안에 끝나는 것만.** 여기 검사는 매 작업 끝마다 돌기 때문에, 느린 검사를 넣으면
봇 응답이 그만큼 매번 느려집니다. 화면을 돌아다니는 검사는 `../checks-slow/` 로.

기준: 대략 5초를 넘기면 느린 층입니다.
(실측 참고 — calc 3초 / pay 31초 / flow 68초 / cards 72초 / overflow 140초)

## 넣기 전에 반드시

**일부러 고장 내서 실패로 잡히는지 확인하십시오.** 안 걸리는 검사가 통과하는 것이
제일 나쁩니다. 2026-09-08에 실제로 두 번 겪었습니다 — `flow.cjs`의 문서 검사가 거짓
통과했고, `calc.cjs`의 육합 검사가 0쌍을 찾고도 "전부 통과"라고 했습니다.
