# 느린 층 검사 폴더

여기에 `.cjs` 파일을 넣으면 `bash verify.sh --full`(배포 직전)이 자동으로 돌립니다.

- 통과 = 종료코드 0, 실패 = 0이 아닌 값
- 첫 인자로 로컬 서버 주소가 들어옵니다 (`process.argv[2]`)
- 공용 부품은 `../_lib.cjs`

화면을 실제로 돌아다니거나 여러 폭에서 다시 그리는 검사가 여기 해당합니다.
빠른 층(`../checks/`)에 넣으면 매 작업 끝마다 그 시간을 냅니다.

넣기 전에 **일부러 고장 내서 실패로 잡히는지** 반드시 확인하십시오.
